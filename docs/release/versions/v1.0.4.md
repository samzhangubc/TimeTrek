# Thyme-Me 1.0.4

Thyme-Me 1.0.4 is a surgical Home-layout correction. Application behavior and the
local data format are unchanged from 1.0.3.

## Changes since 1.0.3

- Prevented Stream-card timers, menus, statistics, and action controls from being
  cropped at constrained widths and interface scales.
- Stacked the Stream-card session actions so both remain fully accessible.
- Reflowed the Home header earlier when the window is narrow.

## Install or upgrade

Download `Thyme-Me-1.0.4-win-x64-portable.zip`. Compare its hash with the SHA-256
printed below in the release notes, extract the complete ZIP to a new writable
folder, and run the root `thymeme.exe`. Existing local data remains in the same
Windows application-data location; creating a backup before upgrading is
recommended.

The self-contained x64 build requires no Developer Mode, certificate installation,
administrator access, or system-wide .NET installation. It is intentionally
unsigned, so Windows may show **Unknown publisher** or a Microsoft Defender
SmartScreen warning.
