# Thyme-Me 1.0.3

Thyme-Me 1.0.3 is a surgical release-layout update. Application features and the
local data format are unchanged from 1.0.2.

## Changes since 1.0.2

- Simplified the extracted portable root to `thymeme.exe`, `LICENSE.txt`,
  `NOTICE.txt`, and `files/`.
- Moved the fixed application payload and all other support files below `files/`.
- Limited public release assets to the portable ZIP and `LICENSE`, alongside
  GitHub's generated source-code archives.
- Updated launcher, startup-registration, packaging, metadata, and documentation
  paths for the new layout.

## Install or upgrade

Download `Thyme-Me-1.0.3-win-x64-portable.zip`. Compare its hash with the SHA-256
printed below in the release notes, extract the complete ZIP to a new writable
folder, and run the root `thymeme.exe`. Existing local data remains in the same
Windows application-data location; creating a backup before upgrading is
recommended.

The self-contained x64 build requires no Developer Mode, certificate installation,
administrator access, or system-wide .NET installation. It is intentionally
unsigned, so Windows may show **Unknown publisher** or a Microsoft Defender
SmartScreen warning.
