# Thyme-Me 1.0.2

Thyme-Me 1.0.2 is a maintenance release that completes the public product rename
and makes the source repository easier to navigate. The local-first time-tracking
features and data format remain compatible with version 1.0.1.

## Changes since 1.0.1

- Renamed the application, executable, projects, namespaces, and release identity
  from TimeTrek to Thyme-Me; the executable is now `thymeme.exe`.
- Centralized public product identity while retaining support for restoring backup
  archives created under the TimeTrek name.
- Renamed the solution and source/test projects to consistent `ThymeMe` code names.
- Reorganized product, engineering, release, and legal documentation behind a
  single documentation index for faster human and coding-assistant navigation.
- Updated packaging, legal-document links, GitHub workflows, and user instructions
  for the new paths and artifact names.

## Install or upgrade

Download `Thyme-Me-1.0.2-win-x64-portable.zip` and `SHA256SUMS.txt` from this
release. Verify the checksum, extract the complete ZIP to a new writable folder,
and run `thymeme.exe`. Existing local data remains in the same Windows
application-data location; creating a backup before upgrading is recommended.

This self-contained x64 build includes its required .NET and Windows App SDK
runtime files. It requires no Developer Mode, certificate installation,
administrator access, or system-wide .NET installation.

## Platform and trust notice

- Windows 11 x64 is supported without a support SLA.
- Windows 10 22H2 x64 remains a compatibility-only target.
- The executable is intentionally unsigned, so Windows may show **Unknown
  publisher** or a Microsoft Defender SmartScreen warning.
- SHA-256 checksums, an SPDX SBOM, and GitHub artifact attestations are published
  with the release for integrity and provenance verification.

Google Drive backup and synchronization remain a development plan and are not
included in this release.
