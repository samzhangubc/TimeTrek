# Thyme-Me 1.0.1

Thyme-Me's first public release packages the complete local-first Windows time
tracking baseline for x64 computers.

## Highlights

- Mixer-style Stream workspace with one global timing transport.
- Normal and Pomodoro timing, pause/resume, completion notes, and crash recovery.
- History, Stats, timeline, budgets, billing, rounding, archive, and recovery.
- Local JSON/CSV export and validated backup/restore.
- Optional local foreground-application summaries with explicit consent.
- Responsive layouts, whole-interface scaling, notification-area timing, and
  first-run setup.
- Self-contained portable x64 application; no separate .NET or Windows App SDK installation.

## Platforms

- Windows 11 x64 is supported without an SLA.
- Windows 10 22H2 x64 is compatibility-tested only when identified as verified in
  the published release evidence.

## Installation

Download `TimeTrek-1.0.1-win-x64-portable.zip` from the GitHub Release, verify its
SHA-256 checksum, extract the whole archive to a writable folder, and run
`TimeTrek.App.exe`. The executable is intentionally unsigned, so Windows may show
**Unknown publisher** or a Microsoft Defender SmartScreen warning. Developer Mode
and manual certificate installation are not required.
